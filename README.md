# Technova-Sales-Dashboard
Power BI Sales &amp; Employee Performance Dashboard
TECHNOVA SALES & EMPLOYEE PERFORMANCE DASHBOARD
 Overview

This project is Power BI dashboard developed to analyze Technova's sales and employee performance. The dashboard provides business insights into regional sales, product performance, employee performance, and monthly sales trends to support data-driven decision-making.

---

Project Objectives

- Analyze sales performance by region.
- Identify the top 5 selling products.
- Monitor monthly sales trends.
- Evaluate employee performance against sales targets.
- Identify bonus-eligible employees.
- Provide interactive filtering and drill-through functionality.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

Data Preparation

The dataset was imported into Power BI from Microsoft Excel.

The following data preparation steps were carried out:

- Cleaned and transformed data using Power Query
- Verified data types
- Established relationships between tables
- Created a Date Table for time-based analysis
- Developed DAX measures for business calculations

DAX Measures Created

- Total Sales
- Total Actual Sales
- Total Sales Target
- Sales Variance
- Bonus Eligible Employees


Dashboard Features

KPI Cards
- Total Sales
- Sales Variance
- Total Actual Sales
- Total Sales Target
- Bonus Eligible Employees

Visualizations
- Sales by Region (Bar Chart)
- Top 5 Products by Sales (Pie Chart)
- Monthly Sales Trend (Line Chart)
- Employee Performance Table with Conditional Formatting

 Interactive Features
- Region Slicer
- Category Slicer
- Drill-through to Employee Details
- Data Refresh

---
Key Insights

- East region recorded the highest sales.
- South region recorded the lowest sales.
- April had the highest monthly sales.
- February recorded the lowest monthly sales.
- Employees who achieved their targets were identified as bonus eligible.

---

Recommendations

- Improve sales performance in lower-performing regions.
- Provide coaching and support to employees who did not meet their sales targets.
- Continue investing in top-performing products.
- Monitor sales trends regularly using the dashboard for better business decisions.
